## 后续需要真实环境验证的范围

- 浏览器多配置、Electron、Flatpak、Steam/Wine 和 gamescope 的实际元数据组合。共享窗口类且不提供应用 ID/启动信息的程序仍可能存在歧义，不能以合成 GTK 窗口测试承诺所有程序兼容。
- 多显示器、混合 DPI、显示器热插拔、面板自动隐藏与实际鼠标设备的组合。图标缩放和缓存失效已经实现，但这些硬件组合尚未穷举。
- 长时间连续使用、音频服务反复断开与重连、大量窗口及音频流的压力测试。现有短期测试不替代长期稳定性记录。
- 对确实无法自动区分的多配置启动器，可在实际样例的基础上进一步提供手动映射；应用级音频控制仍受共享音频进程的粒度限制。

继续采用本地验证，不增加 GitHub Actions。每项结果区分代码实现、隔离测试和真实设备验证，出现实际问题后以最小复现补充回归。
